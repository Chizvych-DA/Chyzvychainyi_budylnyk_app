# Будильник: приложение для Android

Управляет часами по Wi-Fi: расписание по дням, яркость, цветовые схемы, фон за часами,
эффекты будильника, реакция на касание, громкость, трек, повторные звонки, часовой пояс,
время и Wi-Fi часов. Все настройки те же, что в веб-интерфейсе, и они сохраняются в самих часах.

Прошивку менять не нужно: приложение работает с тем же API (`/api/...`), что и веб-страница.
Работает только в одной Wi-Fi сети с часами. Пароля нет, как и у веб-страницы.

## Как получить APK (способ 1: без установки программ)

1. Зарегистрируйся на github.com (бесплатно) и создай новый **приватный** репозиторий.
2. Распакуй этот архив и загрузи всё его содержимое в репозиторий:
   «Add file» → «Upload files» → перетащи все файлы и папки (в том числе папку `.github`).
   Если папка `.github` не загрузилась, создай файл вручную:
   «Add file» → «Create new file», имя `.github/workflows/build.yml`, и вставь в него
   содержимое файла `.github/workflows/build.yml` из архива.
3. Открой вкладку **Actions**. Сборка запускается сама после загрузки (при необходимости
   нажми «I understand my workflows, go ahead and enable them»). Она идёт около 3-5 минут.
4. Когда сборка станет зелёной, открой её и внизу в разделе **Artifacts** скачай
   `alarm-clock-apk`. Внутри zip лежит `app-debug.apk`.

## Способ 2: Android Studio

1. Установи Android Studio, выбери «Open» и укажи папку проекта.
2. Дождись синхронизации Gradle (понадобится интернет). Если студия предложит обновить
   плагин Android Gradle, соглашайся.
3. Подключи телефон по USB (включи «Отладка по USB») и нажми «Run», либо
   Build → Build APK(s).

## Установка на телефон

1. Скопируй `app-debug.apk` на телефон и открой его.
2. Разреши установку из этого источника, если система спросит.
3. Если Play Protect пишет, что приложение не проверено, выбери «Всё равно установить».
   Приложение подписано собственным ключом, поэтому предупреждение нормальное.
4. Новые версии APK устанавливаются поверх старой без удаления (ключ подписи постоянный).

## Первый запуск

1. Подключи телефон к той же Wi-Fi сети, что и часы.
2. Открой приложение. Оно само найдёт часы (через mDNS, а если не получится, переберёт
   адреса своей сети) и откроет настройки. Адрес запоминается.
3. Если часы не нашлись, введи их адрес вручную (он виден в мониторе порта Arduino, например
   `192.168.0.94`, и в списке устройств роутера).

## Если не подключается

- Телефон и часы должны быть в одной сети. Гостевая сеть и «изоляция клиентов» (AP isolation)
  в роутере мешают: отключи их.
- Если адрес часов меняется после перезагрузки роутера, закрепи за часами постоянный адрес
  в настройках роутера (DHCP reservation), тогда приложение будет подключаться мгновенно.
- Часы сами недоступны: проверь, открывается ли страница `http://адрес-часов` в браузере телефона.

## Что внутри

- `app/src/main/java/com/example/alarmclock/MainActivity.kt`: экраны и настройки
- `Net.kt`: запросы к часам, поиск часов в сети
- `Models.kt`: состояние и настройки часов
- `.github/workflows/build.yml`: облачная сборка APK
